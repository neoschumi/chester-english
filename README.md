# 拼讀大冒險 Phonics Adventure

給台灣小朋友的英文自然發音（phonics）闖關網頁。純 HTML / CSS / JavaScript，不需要伺服器，可直接用 GitHub Pages 發佈，在 iPad 上使用。

## 內容

13 個單元，分三個階段，難度由基礎銜接到中高年級：

| 階段 | 單元 |
|---|---|
| 一、基礎拼讀 | 字母聲音、短母音、子音組合、雙字母音 |
| 二、長母音與母音組合 | 魔法 e、母音組合、r 控制母音、特殊母音（oo/ou/oi/aw） |
| 三、進階拼寫（中高年級） | 不發音字母、高頻字、字首與字尾、音節、常見字尾（-tion/-ture） |

每個單元的流程：**聽 Listen → 說 Say → 玩 Play → 測驗 Quiz**

- 聽：點卡片聽發音，可「全部播放」
- 說：聽標準發音、慢速、錄下自己的聲音再播放比一比（不上傳、不儲存）
- 玩：聽音配對記憶遊戲
- 測驗：10 題，1～5 顆星（60/70/80/90/100%），預設 3 顆星（80%）過關才解鎖下一關
- 首次可做「分級測驗」，會的單元直接跳過
- 錯字自動進入「複習清單」
- 成就徽章、等級稱號、連續學習天數
- 家長專區（算式題擋住）：進度圖表、紀錄、常錯字、目標與獎勵、設定、備份還原

## 上傳到 GitHub 並開啟 Pages

1. 登入 GitHub，右上角 **+ → New repository**，名稱例如 `phonics-adventure`，選 **Public**，建立。
2. 在新 repo 頁面點 **uploading an existing file**，把這個資料夾裡的**所有檔案**拖進去
   （`index.html`、`app.js`、`data.js`、`style.css`、`manifest.json`、`icon-180.png`、`icon-512.png`），按 **Commit changes**。
   注意：檔案要直接放在 repo 根目錄，不要多包一層資料夾。
3. 到 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾 `/ (root)`，按 Save。
4. 等 1～2 分鐘，網址會是 `https://你的帳號.github.io/phonics-adventure/`。

## 在 iPad 上使用

1. 用 **Safari** 開啟網址。
2. 點分享按鈕 → **加入主畫面**，之後就像 App 一樣開啟，資料也比較不會被 Safari 清除。
3. 第一次錄音時會詢問麥克風權限，請按「允許」。
4. 建議橫向使用。語音使用 iPad 內建語音；想要更自然的聲音，到「設定 → 輔助使用 → 語音內容 → 聲音 → 英文」下載 Enhanced / Premium 語音，再到家長專區選擇。

## 資料與備份

- 學習紀錄只存在**這台 iPad 的瀏覽器**（localStorage），不會上傳。
- 請定期到 **家長專區 → 設定與備份 → 下載備份檔**，換裝置或資料遺失時可還原。
- 更新網頁檔案（例如新增單字）不會影響已儲存的紀錄。

## 自己新增單字

打開 `data.js`，在對應單元的 `raw` 陣列加一行：

```
'單字|中文|圖示emoji(可留空)|拼法規則(可留空)'
```

拼法規則範例：`sh`（一般組合）、`a_e`（魔法 e）、`un-`（字首）、`-ful`（字尾）。
音節單元用 `-` 分開，例如 `'ba-na-na|香蕉|🍌'`。改完上傳覆蓋即可。

## 已知限制

- 語音合成念「單一音素」（如 /b/）不夠準，所以用「B as in ball」的單字示範；網頁也無法判斷孩子的發音對不對，錄音比一比的目的是讓孩子自己聽，再由家長糾正。
- 目前還沒有的內容：句子閱讀、主題單字（動物、食物等）、更多遊戲。架構是資料驅動的，之後可以擴充。
